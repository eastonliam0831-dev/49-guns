# Gun Bow Skins (Fabric, client-side, MC 26.3)
Cosmetic only: the bow *looks* like a gun. It still shoots arrows. Nothing is sent to servers.

Keys (rebindable): G next skin, H previous skin, J back to vanilla bow.
You can also pick any skin manually in Options > Resource Packs ("Bow: Glock 17", ...).

## Build
JDK 25 required.  `gradle wrapper` (once, Gradle 9.6) then `./gradlew build` -> build/libs/gunbow-1.0.0.jar
If the build setup misbehaves, generate a fresh 26.3 project at https://fabricmc.net/develop/template/ and copy `src/` into it.

## Replace the placeholder art
Models are 3D cuboid models generated by `gen.py` (palette texture, one unique accent color per gun).
Edit shapes in gen.py (build functions) or hand-edit `resourcepacks/<gun>/assets/minecraft/models/item/gunbow_<gun>.json` (Blockbench works), then rebuild.
Resourcepack format is 97 for 26.3 (PACK_FORMAT in gen.py; re-run `python3 gen.py` to regenerate everything).

## Hand position / direction
If a gun points at you or floats oddly in hand, edit HAND_ROT / HAND_BASE_* / HAND_SCALE_* at the top of gen.py and run `python3 gen.py`.
Tip: with the game running, rebuild the jar or edit the pack in place and press F3+T to reload.
